# Unit cost breakdown design

## Intent

ทำให้ผู้ใช้เริ่มวางแผนจากต้นทุนแต่ละรายการก่อนเห็นราคาขายและยอดขาย เพื่อมองเห็นกำไรจริงต่อชิ้นได้ชัดขึ้น

## Selected layout

1. ต้นทุนสินค้า/ชิ้น
2. ค่าบรรจุภัณฑ์/ชิ้น
3. ค่าขนส่ง/ชิ้น
4. ราคาขาย/ชิ้น
5. ยอดขายต่อเดือน

## Calculation

- ต้นทุนรวมต่อชิ้น = ต้นทุนสินค้า + ค่าบรรจุภัณฑ์ + ค่าขนส่ง
- ยอดขายต่อเดือน = ราคาขาย × ยอดขายต่อเดือน
- กำไรขั้นต้นต่อเดือน = (ราคาขาย − ต้นทุนรวมต่อชิ้น) × ยอดขายต่อเดือน
- อัตรากำไร = กำไรขั้นต้น ÷ ยอดขาย

## Existing data compatibility

- ค่า `cost` เดิมกลายเป็นต้นทุนสินค้าโดยอัตโนมัติ
- `packagingCost` และ `shippingCost` ที่ยังไม่มีในข้อมูลเดิมเริ่มต้นเป็น 0
- ห้องแชร์ ลิงก์ และข้อมูลที่บันทึกไว้ยังเปิดได้ และกำไรเดิมไม่เปลี่ยนจนกว่าจะกรอกต้นทุนใหม่

## Approaches considered

- เลือกใช้ต้นทุนทุกชนิดเป็นจำนวนเงินต่อชิ้น เพราะกรอกและเปรียบเทียบง่ายที่สุด
- ไม่เลือกค่าธรรมเนียมแพลตฟอร์มในรอบนี้ เพราะมักเป็นเปอร์เซ็นต์และต้องมีรูปแบบการคำนวณเพิ่ม
- ไม่รวมทุกอย่างไว้ในช่องต้นทุนเดียว เพราะไม่ตอบเป้าหมายเรื่องการเห็นที่มาของต้นทุน

## Constraints and non-goals

- ช่องทั้งหมดพิมพ์เลขและเลื่อนได้เหมือนเดิม
- ค่าติดลบถูกป้องกันเหมือนเดิม
- รอบนี้ยังไม่เพิ่มภาษี ส่วนลด หรือค่าธรรมเนียมแบบเปอร์เซ็นต์
- ต้องมีการทดสอบสูตรใหม่และข้อมูลเก่าก่อนเปลี่ยนโค้ดจริง
