# Flexible Costs and Variable Breakdown Design

## Intent

ให้ผู้ใช้สร้างรายการต้นทุนต่อชิ้นได้เอง เปลี่ยนชื่อและค่าได้ และเห็นว่าราคาขาย 100% ถูกใช้ไปกับต้นทุนแต่ละรายการและเหลือเป็นกำไรเท่าไรโดยอัตโนมัติ

## Chosen approach

เก็บต้นทุนเป็น `costItems` ภายในแต่ละชุด แต่แปลงข้อมูลเดิมจาก `cost`, `packagingCost`, `shippingCost` อัตโนมัติ รายการต้นทุนทุกแถวมี `id`, `label`, `value`; เพิ่ม ลบ เปลี่ยนชื่อ และเปลี่ยนค่าได้ รายการทั้งหมดถูกหักจากกำไรและเดินทางไปกับ local save, share และ realtime state เดิม

พิจารณาอีกสองทางแล้วไม่เลือก: คงฟิลด์ตายตัวแล้วเพิ่ม `extraCosts` จะทำให้ UI และสูตรมีข้อมูลสองแบบ; ใช้แถบอิสระเดิมเป็นแถบต้นทุนจะทำให้การปรับด้วยมือขัดกับค่าที่คำนวณอัตโนมัติ

## UI behavior

- แถวต้นทุนอยู่ก่อนราคาขาย มีปุ่ม `＋ เพิ่มแถว` และชื่อแต่ละแถวแก้ไขได้
- รายการเริ่มต้นคือ ต้นทุนสินค้า/ชิ้น, ค่าบรรจุภัณฑ์/ชิ้น, ค่าขนส่ง/ชิ้น
- รายการเพิ่มใหม่ชื่อ `ต้นทุนเพิ่มเติม/ชิ้น` ค่า 0 และลบได้; ต้องเหลืออย่างน้อยหนึ่งรายการ
- เปลี่ยนคำว่า `ยอดขายต่อเดือน` เป็น `ยอดขาย` และ `กำไรขั้นต้นต่อเดือน` เป็น `กำไรขั้นต้น`
- เพิ่ม `แบ่งสัดส่วนแปรผันตาม` เหนือส่วนเดิม ใช้ราคาขายเป็น 100% แสดงต้นทุนทุกรายการและกำไรคงเหลือแบบอ่านอย่างเดียว
- เปลี่ยนหัวข้อเดิมเป็น `แบ่งสัดส่วน (อิสระ)` โดยพฤติกรรมเดิมทั้งหมดคงอยู่
- ถ้าต้นทุนรวมเกินราคาขาย แสดงผลขาดทุนและทำให้แถบต้นทุนเต็มพื้นที่โดยไม่แสดงเปอร์เซ็นต์หลอกว่าเท่ากับ 100%; ตัวเลขเปอร์เซ็นต์จริงยังแสดงในรายการ

## Compatibility and limits

- ข้อมูลเก่าต้องรักษาค่าต้นทุนทั้งสามรายการไว้
- ชื่อยาวไม่เกิน 40 ตัวอักษร ค่าอยู่ช่วง 0–100,000,000 และมีรายการสูงสุด 12 รายการต่อชุด
- การแก้ไขทั้งหมดรองรับ undo, duplicate, save, share และ realtime ผ่าน state เดิม
